## One-line answers

- **Where do mods live?** `<game>\mods`, one folder each.
- **Where are my original files?** `<game>\mod-backup`. They're copied there the first time a mod changes them.
- **How do I undo everything?** Mods › Restore Original Game.
- **Does it change my save?** No.
- **Does it work online?** It's for offline play. Don't take modded files or code mods online.
- **Something broke.** Settings › Open Log, and send that file with what you were doing.
