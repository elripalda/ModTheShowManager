# Mod the Show Manager 0.14

- **Code mods on any game update.** They now find their place in whichever update you have installed.
- **Effects** in Code Mods (experimental): a fireball on hard pitches, hot streaks and fireworks, all drawn by the manager.
- A **Gravity** dial, and more body shapes in Arcade Rosters.
- General improvements and fixes across the app.

Press Rebuild Game once in Code Mods after updating. Keep the logs coming (Settings › Open Log).
