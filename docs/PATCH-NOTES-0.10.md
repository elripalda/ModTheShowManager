# Mod the Show Manager 0.10

The first build of Mod the Show Manager, a mod manager for the MLB The Show 26 PC recomp (the Nintendo Switch
version, running on [mlbts-native](https://github.com/sam110411/mlbts-native)).

## What's in it

- **Mods:** switch them on and off, set the order, apply. Every file a mod changes is backed up first, and
  Restore Original Game puts the stock game back.
- **Textures:** uniforms, bats, stadiums, scorebugs, menus and loading screens. Preview, export, replace.
- **Uniforms on a player**, the uniform schedule, and a 3D view of every ballpark.
- **Scorebug layout:** move and scale it.
- **Teams & Rosters:** edit players, ratings, gear and lineups. Import and export rosters as a plain file.
- **Sounds:** every sound in the game plays and exports, commentary included. Replace streams with your own WAV.
- **3D Models:** view, export and replace bats, balls and props.
- **Code mods:** Auto PCI, moonshot home runs, juiced ball, thin air and more, switched per launch.
- **Launcher:** see what state the game is in and press Play.
- **Sample Mods:** four ready-made mods built from your own game files.
- Dark, Light and OLED looks, and an update check.

## What you need

- Windows 10 or 11.
- The MLB The Show 26 PC recomp, installed and working, from your own copy of the game.
- For code mods: the recomp's own folder, since the game is rebuilt.

## Downloads

- `ModTheShowManager-Setup.exe`: the installer. Most people want this.
- `ModTheShowManager.exe`: the same app without installing.
- `ModTheShowManager-source.zip`: the source for this build.

Start with the [quick start](https://github.com/elripalda/ModTheShowManager/blob/main/docs/QUICK_START.md).

This is an early build and mods are for offline play. If something goes wrong, open **Settings › Open Log** and
send it over with what you were doing. Keep the logs coming, they're how this gets better.
