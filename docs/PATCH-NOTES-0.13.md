# Mod the Show Manager 0.13

- **F4 in fullscreen:** the in-game code mod list is drawn by the game itself now, so it shows in fullscreen.
- **Roster mods combine.** A ratings mod and a bats mod can both be on; each one's changes are kept.
- **Aluminum bats** show in a player's bat list, and Sample Mods has them at the top.
- **Rebuild Game** is always there when you want it, and the page is clearer about when you need it.
- General improvements and fixes across the app.

Press Rebuild Game once in Code Mods after updating. Keep the logs coming (Settings › Open Log).
