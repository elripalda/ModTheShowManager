# Mod the Show Manager 0.12

- **Code Mods** is one page now: every code mod in one list, each with one switch and a plain description.
  Rebuild the game once and they are all there.
- **F4 in the game** opens the same list, so you can switch mods and turn their dials while you play.
- **Dials:** exit velocity, pitch speed, pitch break, the air, how the ball bounces and how hard a bunt comes off
  the bat. Some of these are new and marked Experimental.
- **See it working:** after a game the page shows what the game recorded, like the hardest ball hit and how far
  pitches broke.
- **Arcade Rosters** can hand a whole league aluminum bats, big heads or new body shapes.
- **Make your own:** a starter file and a step-by-step guide, and Import for code mods other people send you.
- General improvements and fixes across the app.

Press Rebuild Game once in Code Mods after updating. Keep the logs coming (Settings › Open Log).
